## 개발 환경

| 구분 | 구성 |
|---|---|
| FPGA 보드 | Zybo Z7-20 / Zynq-7000 · `xc7z020clg400-1` |
| 설계 도구 | Vivado 2025.1 · Vitis |
| 프로세서 애플리케이션 | Cortex-A9 / standalone / C++ |
| 영상 입력 | OV5640 / Pcam 5C · MIPI 수신 IP |
| 하드웨어 자료 | Vivado 프로젝트, 블록 설계, RTL, XSA |
| 소프트웨어 자료 | Vitis 컴포넌트, 카메라·VDMA 제어, SNN 가중치 헤더 |

## 프로젝트 구성 순서

1. 원본 `hw.xpr`을 열고 IP 경로와 참조 RTL을 설정합니다.
2. 사용할 하드웨어의 XSA로 Vitis 플랫폼을 구성하고 BSP와 `xparameters.h`를 생성합니다.
3. 애플리케이션의 플랫폼 참조, VDMA 주소·인터럽트·메모리 영역을 해당 하드웨어에 맞춥니다.
4. RTL·가중치·bitstream·XSA·Vitis 실행 파일을 같은 빌드로 묶어 관리합니다.
5. 카메라 출력 → 그레이스케일 저장 → 차분 영상 → 가중치 로드 → 분류 결과 순서로 동작을 확인합니다.

새 개발 환경에서는 `app_component/vitis-comp.json`의 플랫폼 이름과 경로를 사용할 플랫폼으로 지정합니다. 원본 저장소에는 `platform_0515_2`, `platform_8` 등의 플랫폼 자료가 함께 있습니다.

## UART 관찰 도구

C++ 애플리케이션에서 160 × 90 PGM 형식의 원본·차분 영상과 SNN 결과를 출력할 수 있습니다.

| 명령 | 기능 |
|---|---|
| `y` | 그레이스케일 원본 프레임 덤프 |
| `z` | 차분 프레임 덤프 |
| `r` | SNN 결과 한 번 읽기 |
| `s` | SNN 결과 연속 출력, 리셋으로 종료 |

영상 덤프를 저장할 때는 UART 메뉴·진단 문자열과 PGM 영상 데이터를 구분합니다. 분류 결과와 출력 뉴런의 스파이크 수를 함께 보면 영상 입력부터 추론 결과까지 단계별로 살펴볼 수 있습니다.
