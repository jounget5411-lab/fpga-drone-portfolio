# Visual assets

- `hero.svg` / `hero.png`: 프로젝트 소개용 개념 이미지
- `architecture.svg` / `architecture.png`: 코드에서 확인한 처리 구조
- `prototype.jpg`: 프로젝트 수행 기록에 수록한 실제 팬틸트 시제품 사진
- `detection-comparison.jpg`: 수행 기록의 소프트웨어·INT8 하드웨어 검출 박스 비교 화면
- `current-measurement.png`: 수행 기록의 상태별 입력 전류 비교 그래프

`hero`와 `architecture`의 도형·레이아웃은 이 포트폴리오를 위해 제작했습니다. 경로 모양, 격자 활성 패턴, 노드 배치는 설명용입니다.

`prototype`, `detection-comparison`, `current-measurement`는 프로젝트 수행 기록에서 가져온 원본 이미지입니다. 이미지 내용은 수정하지 않았으며, 각 이미지의 사용 위치에 무엇을 보여 주는지와 검증 범위를 표시했습니다. 기록 원문에 포함된 개인정보와 비공개 문서 링크는 복제하지 않았습니다.

SVG는 수정 가능한 원본이고 PNG는 GitHub 표시 호환성을 위한 이미지입니다. 폰트는 Malgun Gothic / Segoe UI / Arial 계열을 사용합니다.
