# Visual assets

- `hero.svg` / `hero.png`: 프로젝트 소개용 개념 이미지
- `architecture.svg` / `architecture.png`: 영상 처리·SNN 추론 구조
- `prototype.jpg`: 팬틸트 시제품 사진
- `detection-comparison.jpg`: 소프트웨어·INT8 하드웨어 검출 박스 비교 화면
- `current-measurement.png`: 상태별 입력 전류 비교 그래프

`hero`와 `architecture`의 도형·레이아웃은 이 포트폴리오를 위해 제작했습니다. 경로 모양, 격자 활성 패턴, 노드 배치는 설명용입니다.

`prototype`, `detection-comparison`, `current-measurement`는 프로젝트 수행 기록의 원본 이미지입니다.

SVG는 수정 가능한 원본이고 PNG는 GitHub 표시 호환성을 위한 이미지입니다. 폰트는 Malgun Gothic / Segoe UI / Arial 계열을 사용합니다.
